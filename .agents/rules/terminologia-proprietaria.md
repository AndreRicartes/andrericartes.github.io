A. Regra de Terminologia Proprietária
Garante que termos como "Benfeitoria Biológica" ou "Inércia Produtiva" sejam sempre escritos corretamente e acompanhados de uma explicação técnica ou link interno.

B. Regra de Ativos de Alta Resolução
Como você mencionou que o Pantanal do Paiaguás exige imagens submétricas (CBERS-4A de 2m), esta regra impediria o upload de arquivos .jpg pesados, forçando o uso de .webp com compressão otimizada para não derrubar a velocidade do site (Core Web Vitals).

C. Regra de "Ganho de Informação" (Information Gain)
Uma regra que sinaliza se o texto for curto demais ou muito genérico. Para o seu nicho, um post de 300 palavras é irrelevante; as Rules podem exigir um mínimo de 1.000 palavras para artigos marcados como "Análise".

D. Regra de Call-to-Action (CTA) Contextual
Se o post for sobre "Posse", a regra verifica se existe um link para "Consultoria". Se for sobre "Big Data", verifica se há link para seu GitHub.
